# DICOM 3断面ビューワー & 3D肺ボリュームレンダリング

知能情報実験実習2 医用画像処理実験 最終課題のアプリケーションです。

## 1. 動作環境
* **Python**: 3.11.9
* **OS**: Windows 10 / 11

## 2. インストール手順
仮想環境を作成し、`requirements.txt` から必要なライブラリをインストールしてください。

```bash
# 仮想環境の作成
python -m venv venv

# 仮想環境の有効化（Windowsの場合）
venv\Scripts\activate
# ※macOS/Linuxの場合は: source venv/bin/activate

# 必要パッケージのインストール
pip install -r requirements.txt
```

## 3. 起動方法
仮想環境を有効化した状態で、以下のコマンドを実行します。

```bash
python main.py
```

## 4. 操作方法
1. **DICOMデータの読み込み（観点1, 2）**
   * 画面左上のメニューバーから **`ファイル(F)` -> `DICOMフォルダを開く...`** をクリックし、DICOMファイル（`.dcm`）が格納されたフォルダを選択します。
2. **3断面表示とクロスヘア（観点3, 4）**
   * 読み込みが完了すると、**Axial（水平断）**、**Coronal（冠状断）**、**Sagittal（矢状断）** の3断面が表示されます。
   * 各画像上の緑色の十字線は、他の2断面の現在のスライス位置を示しています。
3. **スライダー操作と連動（観点5, 6）**
   * **スライス位置（Axial / Coronal / Sagittal）**: 各断面のスライス位置を変更します。変更に合わせて他の2断面の緑色の線もリアルタイムに連動します。
   * **階調変換（WL / WW）**: ウィンドウレベル（WL）とウィンドウ幅（WW）を変更し、画像のコントラストや明るさを調整できます。
4. **肺領域の3Dボリュームレンダリング表示（観点7）**
   * DICOMデータ読み込み後、画面右下の **`肺領域を3D表示 (ボリュームレンダリング)`** ボタン（またはメニュー内の同項目）をクリックすると、抽出した肺領域の3D表示ウィンドウが起動します。
   * 3Dウィンドウ内では、マウスの左ドラッグで回転、ホイールで拡大・縮小、右ドラッグで平行移動が可能です。
